# 剪贴板猫娘（neko_clipboard_watcher）

> 感知类插件，独立于定时关怀类（猫娘每日关怀）。监听剪贴板变化，猫娘看到主人复制了什么就主动搭话喵～

- 版本：`0.1.0`
- 作者：MENGYAOYUE
- 适用：N.E.K.O 插件运行时（SDK `>=0.1.0, <0.3.0`）
- 依赖：零第三方库（ctypes 读剪贴板，纯标准库）

## 功能

- **主动搭话**：复制链接 → "要不要本喵看看里面是什么"；代码 → "这段代码有故事喵"；英文 → "要翻译吗"；长文 → "要总结吗"
- **隐私优先**：疑似密码/密钥/令牌（password、token、api_key、私钥块、sk-…、ghp_… 等）**看都不看**，也不落盘
- **节奏控制**：同一内容不重复评论、两次搭话至少间隔 `cooldown_seconds`、每小时最多 `max_per_hour` 次
- **总开关**：入口 `set_enabled`（聊天里说"关掉剪贴板监听"即可触发），持久化重启不丢

## 使用

- 聊天里说 **"看看我的剪贴板"**：猫娘读取当前剪贴板并分类搭话（入口 `clipboard_now`）
- 开关与状态：入口 `set_enabled` / `status`
- 自然语言命令插件可跨插件调用：`neko_clipboard_watcher:clipboard_now`

## 配置（`[neko_clipboard_watcher]` 段）

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `poll_interval_seconds` | 2 | 剪贴板轮询间隔（秒，最小 1） |
| `cooldown_seconds` | 600 | 两次主动搭话的最小间隔（秒，最小 10） |
| `max_per_hour` | 6 | 每小时最多主动搭话次数 |

## 隐私说明

- 剪贴板的读取与内容分类都在本机完成，识别为密码/密钥的内容看都不看
- 非敏感内容会截取前 200 字符作为「搭话话题」交给猫娘 AI 生成话术；这一环节是否联网取决于你为 N.E.K.O 配置的模型服务
- 敏感内容（疑似密码/密钥）直接跳过，不进入日志、不持久化
- 持久化的只有内容 SHA-256 哈希（用于去重）与推送时间戳，不保存原文
