# 剪贴板猫娘（neko_clipboard_watcher）

> 感知类插件，独立于定时关怀类（猫娘每日关怀）。监听剪贴板变化，猫娘看到主人复制了什么就主动搭话喵～

- 版本：`0.5.0`
- 作者：MENGYAOYUE
- 适用：N.E.K.O 插件运行时（SDK `>=0.1.0, <0.3.0`）
- 依赖：零第三方库（ctypes 读剪贴板，纯标准库）

## 功能

- **主动搭话**：复制链接 → "要不要看看里面是什么"；代码 → "这段代码有故事喵"；英文 → "要翻译吗"；长文 → "要总结吗"
- **分类更细（v0.5.0）**：链接再分视频 / 代码仓库 / 文档 / 商品 / 社交 / 图片 / 文件；另有报错栈、表格、命令、磁力直链、联系方式（**只给掩码**）
- **剪贴板历史**：最近 60 条只记「分类 + 掩码预览 + 有没有开口」，可一键清空；不存正文
- **按分类开关**：哪类内容不想被搭话就单独关掉（敏感内容不在此列，永远不读）
- **静音时段**：例如 23:30–08:00 不主动开口，跨零点也支持
- **隐私优先**：疑似密码/密钥/令牌（password、token、api_key、私钥块、sk-…、ghp_… 等）**看都不看**，也不落盘
- **节奏控制**：同一内容不重复评论、两次搭话至少间隔 `cooldown_seconds`、每小时最多 `max_per_hour` 次
- **总开关**：入口 `set_enabled`（聊天里说"关掉剪贴板监听"即可触发），持久化重启不丢

## 使用

- 聊天里说 **"看看我的剪贴板"**：猫娘读取当前剪贴板并分类搭话（入口 `clipboard_now`）
- 开关与状态：入口 `set_enabled` / `status`
- 自然语言命令插件可跨插件调用：`neko_clipboard_watcher:clipboard_now`

## 配置（`[neko_clipboard_watcher]` 段）

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `poll_interval_seconds` | 2 | 剪贴板轮询间隔（秒，最小 1） |
| `cooldown_seconds` | 5 | 两次主动搭话的最小间隔（秒，最小 2） |
| `max_per_hour` | 30 | 每小时最多主动搭话次数 |
| `max_snippet_chars` | 0 | 交给猫娘的片段长度上限（字）。**0 = 不限制**，复制多长就读多长；填了数字才会截断并加省略号 |

面板里另外可调：分类开关、静音时段、历史清空（都写在 `data/clipboard_state.json`，不进发行包）。

## 隐私说明

- 剪贴板的读取与内容分类都在本机完成，识别为密码/密钥的内容看都不看
- 非敏感内容会原样（默认不截断）作为「搭话话题」交给猫娘 AI 生成话术；需要限长可在面板「限速」页设 `max_snippet_chars`。这一环节是否联网取决于你为 N.E.K.O 配置的模型服务
- 敏感内容（疑似密码/密钥）直接跳过，不进入日志、不持久化
- 持久化的只有内容 SHA-256 哈希（用于去重）与推送时间戳
- **v0.5.0 的历史列表同样不存正文**：链接只留域名、代码只留首行、联系方式打码、纯文本/长文只记字数

## 面板（v0.5.0 新增）

- **按分类开口**：一排小胶囊，点一下关掉某一类（关掉只是不主动开口，手动"看看剪贴板"照旧可用）
- **静音时段**：两个输入框（如 `23:30` / `08:00`），保存后猫娘在这段时间内不主动搭话
- **剪贴板历史**：倒序列出最近 60 条，灰色表示"复制了但没开口"，并给出原因（冷却中 / 分类已关闭 / 静音时段…）
